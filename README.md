## Getting Started

These notebooks were developed in Google Colab. To run them:

1. Open a notebook in [Google Colab](https://colab.research.google.com/) or Jupyter.
2. Install any missing dependencies noted in the notebook's import cells (e.g., `pillow`, `scikit-learn`, `matplotlib`, `tensorflow`/`keras`, `torch`).
3. Some notebooks reference external image assets (e.g., `cat.jpg`) that may need to be uploaded to your runtime's working directory.
